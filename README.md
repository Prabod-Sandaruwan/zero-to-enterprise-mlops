# zero-to-enterprise-mlops

## 📌 Overview
This repository serves as my personal laboratory for exploring, learning, and stress-testing modern MLOps practices, cloud-native architectures, and platform engineering patterns. 

Every folder here represents a hands-on experiment, from foundational Python scripting to complex Kubernetes operators.

## 🛠️ Tech Stack (Target)
- **Core**: Python, FastAPI, AsyncIO
- **Containers & Orchestration**: Docker, Kubernetes (AKS), Helm
- **MLOps Tools**: MLflow, KServe, Triton Inference Server
- **Data & Vector**: PostgreSQL, Milvus
- **GitOps & CI/CD**: ArgoCD, GitHub Actions
- **Observability**: Prometheus, OpenTelemetry
